# Developer Cleanup

## Map

Columns: set (a) = Smart Scan, scheduled scans and scheduled cleaning (`CleaningCategory.smartScannable`); set (b) = excluded from Overview totals, selection and every `cleanAll` (`CleaningCategory.overviewExcluded`); set (c) = removal needs the risk-acknowledgement sheet (`RemovalRisk.acknowledgedCategories`). "Overview/cleanAll?" is "yes" when the Overview may count, select and clean the category's rows (not in set b).

Not removal categories: the Space Explorer treemap draws sizes only and deletes nothing ([SPACE-TREEMAP.md](SPACE-TREEMAP.md)). The standalone `cli/` package has its own catalog and rules and is unchanged by these categories.

Rows listed under "Preselected? never" can still be selected by a click on the row. Where the sidebar shows them: `MainWindow.swift` → `advancedCategories`.

Route order in `CleaningEngine.cleanItems` (every early route precedes the generic unlink path): `CleanupExclusions` → AI Apps path check → Local AI Models → AI Agent Data → Purgeable Space → Universal Binaries → Language Files → Dev Tool Caches → Git Worktrees (worktree or artifact row) → Docker prune rows → simulator runtimes → generic path (`hasUnexpectedSymlink`, `isSafeToDelete(item:…)`, `removeItem` or Trash for managed XcodeBuildMCP DerivedData).

## Shared safety model

Each rule names the enforcing code and the test that pins it. Category-specific rules are in the category docs.

1. **One bulk-selection rule.** A row that bulk selection must skip is described by one property, `CleanableItem.isExcludedFromBulkSelection` (`Models.swift`): `selectOnlyByHand` (Maven, NuGet, every model row) OR `requiresExplicitSelection` (Docker volumes, worktree artifact rows) OR `isSelectionBlocked` (protected and unlisted worktrees, artifact rows of a busy worktree). `AppState.isExcludedFromBulkSelection(_:)` adds the one live condition, `isBlockedByRunningApp` (AI Agent Data row whose owning app runs). Every bulk path calls it: `AppState.selectAllInCategory`, `AppState.setSelection(true, …)`, `AppState.categoryBinding` (through `selectAllInCategory`), and the Select visible button (`CategoryDetailView.selectableVisibleItems`). Per-row toggles keep their own rules in `AppState.toggleItem`: a blocked row (`isSelectionBlocked`, running app) is never newly selected, a hand-select-only row is selected by a click. Deselecting in bulk is never restricted. Tests: `CategoryRulesTests.testTheBulkRuleSkipsEveryHandOnlyBlockedAndRunningAppRow`, `testSelectAllInCategorySkipsThemAndKeepsTheControls`, `testSelectVisibleAndSetSelectionSkipThem`, `testCategoryCheckboxSkipsHandOnlyRows`, `testPerRowToggleKeepsItsOwnBlockRules`, `testClearingTheSelectionStillWorksForHandSelectedRows`.
2. **Three explicit category sets.** (a) Smart Scan, scheduled scans and scheduled cleaning: `CleaningCategory.smartScanExcluded` = Git Worktrees, Local AI Models, AI Agent Data; `smartScannable` is `scannable` minus it. Used by `AppState.allResults`, `startSmartScan`, `runScheduledScan`, `AppState.totalJunkSize` (`smartScanTotalSize`), `totalItemCount`, `ScheduleConfig.categoriesToScan`, `CLI.swift` (the built-in `PureMac scan`). (b) Overview and every `cleanAll`: `CleaningCategory.overviewExcluded` = Docker Cache, Git Worktrees, Local AI Models, AI Agent Data, a superset of (a)'s exclusions. Used by `AppState.isReviewedInCategoryOnly`, `overviewSelectedItems`, `totalSelectedSize`, `categoryBinding`, `cleanAll` (manual and scheduled), `retryCleanItems` (Full Disk Access retry), `DashboardView.prepareCleanupConfirmation`. (c) Risk sheet: `RemovalRisk.acknowledgedCategories` = Docker Cache, Git Worktrees, Local AI Models, a subset of (b); `RemovalRisk.risks(for:items:)` lists the risks the user ticks. Docker is in neither exclusion of (a) (Smart Scan sees it) but is in (b) (its prune and volume rows run only from its own screen); AI Agent Data is in (b) but not (c) because it moves to the Trash. Local AI Models is in (c) because removal is permanent and the data is a multi-gigabyte download. Tests: `CategoryRulesTests.testSetAIsSmartScanAndSchedules`, `testSetBIsOverviewAndCleanAll`, `testSetCIsTheRiskSheet`, `testSetsAreConsistentWithEachOther`, `testEveryCategoryHasAnExpectedMembership`, `testAppStateAgreesWithSetB`, `testTheOverviewNeverCountsOrCleansTheExcludedCategoriesEvenWhenEverythingIsSelected`, `testTotalsCountOnlySetA`, `testLocalAIModelsRisksNameThePermanentRemovalSharedBlobsAndRedownload`.
3. **Deny list before allow-list.** `CleaningEngine.isDockerDiskState(_:)` (wrapping `DockerSupport.isProtectedDiskPath`: Docker Desktop and OrbStack VM disks, their containers and every parent folder that would take them along, literal and symlink-resolved) runs before each route's own validation: `isSafeToDelete(item:…)` and `isSafeToDelete(resolvedPath:)` (generic user pass, admin pass, dev tool caches), the Local AI Models route in `cleanItems`, `trashAIAgentDataItem` (item path and validated URL), `removeGitWorktree`, `removeWorktreeArtifacts` (worktree path and every resolved folder). The cloud-provider check (`ProviderPaths.isProviderOwned`, issue #142) precedes the allow-list in `isSafeToDelete(resolvedPath:)` and also runs in `removeGitWorktree`, `removeWorktreeArtifacts` and `LocalAIModels.removalBlock` (before the `hf` CLI and the fallback delete). `allowedDeletionRoots(home:)` keeps upstream's broad roots (`~/Library/Caches`, `~/Library/Application Support`, `~/Library/Containers`, `~/.cache`, …); the developer categories add only exact roots (`DevToolCaches.absolutePaths`, three Docker cache folders). Tests: `DeletionDenyListTests` (`testGenericUserPassRefusesDockerDiskAndItsParents`, `testAdminPassRefusesDockerDisk`, `testDeveloperToolCachesRouteRefusesDockerDisk`, `testLocalAIModelsRouteChecksTheDenyListFirst`, `testAIAgentDataTrashRouteChecksTheDenyListFirst`, `testNothingIsHandedToTheTrashForDockerDisk`, `testWorktreeRemovalChecksTheDenyListFirst`, `testWorktreeArtifactsChecksTheDenyListFirst`, `testDockerCacheFoldersStayCleanable`, `testIsDockerDiskStateCoversDiskParentsAndSymlinkSpellings`), `GitWorktreeScannerTests.testWorktreeInCloudProviderStorageIsNotRemoved`, `testArtifactFoldersInCloudProviderStorageAreLeftAlone`, `LocalAIModelsTests.testRemovalRefusesACacheInCloudProviderStorage`, `DockerSupportTests.testDockerAndOrbStackDisksAreRefusedInUserAndAdminPass`.
4. **Re-validation right before acting.** Nothing trusts the scan. Dev tool caches: `CleaningEngine.isUnchangedDevToolRoot` before the unlink, before `uv`, before `go clean`. Docker volumes: `removeDockerVolumes` re-lists unused volumes. Worktrees: `GitWorktreeScanner.reinspect`, refusal when `Verdict.isWorse`. Artifacts: `checkArtifactFolder` then `WorktreeArtifactSupport.check` again. Models: `LocalAIModels.removeHubEntry` (`classify`, `removalBlock`, again after a CLI attempt), `confirmOllamaDigest`. AI Agent Data: `AIAgentDataSupport.validateForRemoval` (including a fresh process list). Tests: `DevToolCachesTests.testPlainUnlinkIsRefusedWhenTheRootBecomesASymlinkAfterTheFirstChecks`, `DockerSupportTests.testRecordedVolumeThatVanishedOrBecameUsedIsSkippedSilently`, `GitWorktreeScannerTests.testCleaningEngineRechecksBeforeRemoving`, `testEngineRefusesAWorktreeThatGotWorseSinceTheScan`, `testFolderBecomingTrackedAfterTheScanIsLeftAlone`, `LocalAIModelsTests.testFallbackAfterAFailedHFCLIRunsTheFullInspectionAgain`, `testOllamaRemovalSkipsAModelWhoseDigestChangedSinceTheScan`, `AIAgentDataTests.testAppStartedAfterTheScanBlocksRemoval`.
5. **Symlinks and real paths.** Symlinks are never followed by scans, sizes or removal: `DevToolCaches.hasSymlinkBelowHome` (`lstat` per component), `LocalAIModels.classify` (`realpath` must equal root/name), `AIAgentDataSupport.validateForRemoval` (`lstat` per component, `resolvingSymlinksInPath` equals the path), `WorktreeArtifactSupport.check` (`realpath(worktree/path)` equals `realpath(worktree)/path`, same volume), `GitWorktreeScanner.measure`, `CleaningEngine.hasUnexpectedSymlink` (generic route). Tests: `DevToolCachesTests.testCleanRefusesSymlinkedRootAndKeepsTarget`, `LocalAIModelsTests.testRemovalRefusesASymlinkedRepoFolderAndLeavesTheTargetUntouched`, `AIAgentDataTests.testSymlinkedCandidateIsRefusedAndTargetSurvives`, `GitWorktreeScannerTests.testSymlinkedAndEscapingArtifactFoldersAreRefused`, `testSymlinkInsideWorktreeIsNeitherFollowedNorCounted`.
6. **External processes have a timeout and an output limit.** Every command runs through `BrewProcessRunner.run(executableURL:arguments:timeout:environment:keepOutputTail:)` (`ApplicationUpdater.swift`): the process is terminated, then killed, on timeout; stdout and stderr are drained; output past `maxCapturedBytes` (4 MB) fails the run, except `keepOutputTail: true` (Docker prune and `volume rm`) keeps the last `tailWindowBytes` (1 MB). Timeouts: Docker `df` 10 s, lookups 30 s (`DockerSupport.danglingLookupTimeout`), prune 900 s (`DockerSupport.pruneTimeout`); git 20 s (`GitWorktreeScanner.timeout`); dev tools `DevToolCacheEnvironment.commandTimeout` 300 s; models `LocalAIModelsContext.listTimeout` 15 s, `removeTimeout` 120 s, API listing request 5 s. Tests: `DockerSupportTests.testDefaultRunnerStillFailsPastTheOutputCapAndTailModeDoesNot`, `testLongPruneOutputStillYieldsTheSummary`, `DevToolCachesTests.testUVCleanThatWaitsForTheLockPastTheTimeoutIsReportedAsBusy`, `LocalAIModelsTests.testOllamaScanGivesUpOnAHangingCLI`, `testOllamaRemovalReportsFailuresAndTimeouts`.
7. **No shell interpolation.** Commands are executable URL plus argument array; no `sh -c`. Names that reach an argument are validated first: `DockerSupport.isValidVolumeName`, `LocalAIModelsSupport.isValidOllamaModelName`, `GitWorktreeSupport.isValidRevisionName`, exact-root lookup `DevToolCaches.root(forPath:home:)`. The administrator pass (`cleanWithAdminPrivileges`) is the only shell path; it stages NUL-separated paths for `xargs -0` and refuses every developer category except Docker file rows under the three allow-listed cache folders. Tests: `DockerSupportTests.testVolumeNamesAreValidatedSoTheyCannotBecomeOptionsOrPaths`, `GitWorktreeSupportTests.testRevisionNamesCannotInjectGitOptions`, `LocalAIModelsTests.testOllamaRemovalRefusesUnsafeNamesAndRemoteHosts`, `DevToolCachesTests.testRootLookupIsExactMatchOnly`, `testAdminPassRefusesDevToolCaches`, `LocalAIModelsTests.testLocalAIModelRowsNeverReachTheGenericDeleteOrAdminPass`, `AIAgentDataTests.testAdministratorCleaningNeverEscalatesAIAgentData`.
8. **Tests use injected fakes, never the real tool.** `CleaningEngine.init(homeDirectory:dockerBinaryPath:worktreeSettings:devToolEnvironment:localAIModels:isAIAgentOwnerRunning:trashOperation:)` takes a fake docker script path, worktree settings, `DevToolCacheEnvironment` (search directories, process list, timeout), a `LocalAIModels` with a fake `LocalAIModelsContext` (fake `ollama`/`hf` scripts, HTTP closure), an owner-running closure and a Trash closure (`FakeTrash`); `ScanEngine.init(homeDirectory:devToolEnvironment:localAIModels:)` takes the matching ones; `AppState(cleaningEngine:)` takes the engine. Production defaults are unchanged: `.live` environments, real process list, `CleaningEngine.systemTrash`. Fixtures are temp folders under `$TMPDIR`; worktree tests build real throwaway repositories. Tests: `DockerSupportTests` (`makeFakeDockerCLI`), `DevToolCachesTests`, `LocalAIModelsTests`, `AIAgentDataTests.makeEngine`, `GitWorktreeScannerTests.setUpWithError`.
9. **Never touch `~/.claude*`.** `AIAgentDataSupport.isProtectedAgentLocation` (rows can never be produced or removed there), `GitWorktreeSupport.claudeProjectPaths` (reads only the `projects` keys of `~/.claude.json`), `DevToolCaches.roots` (no root equals, contains or sits inside it), `LocalAIModelsSupport.isPlausibleHubRoot`, worktree removal deletes only the worktree folder. Tests: `AIAgentDataTests.testClaudeCodeDataIsNeverRemovedEvenWhenTheItemIsForged`, `testScanNeverProducesClaudeCodeDataEvenWhenItIsHuge`, `GitWorktreeScannerTests.testRemoveDeletesOnlyTheWorktreeAndLeavesClaudeConfigAlone`, `GitWorktreeSupportTests.testClaudeProjectPathsReadsOnlyProjectKeys`, `DevToolCachesTests.testNoRootEqualsContainsOrSitsInsideProtectedLocations`.
10. **User data is never preselected and user exclusions apply first.** Scanners set `isSelected: false` (or `selectOnlyByHand`) for models, AI agent data, artifact rows and Docker virtual rows; `CleanupExclusions` are checked at the top of `cleanItems` before any route. Tests: `LocalAIModelsTests.testBulkSelectionPathsNeverSelectLocalAIModelRowsButDeselectAndClickStillWork`, `AIAgentDataTests.testScanListsOnlyAllowlistedShapesAndLeavesEveryRowUnselected`, `DockerSupportTests.testPruneRowsAreActionItems`, `WorktreeScheduledCleanupTests.testArtifactRowsAreNeverPreselectedBulkSelectedOrScheduled`.

## Debugging

### Where logs go

`Logger.shared.log(_:level:)` (`PureMac/Logic/Utilities/Logger.swift`) writes every message to the unified log through `os.Logger(subsystem: <bundle identifier>, category: "general")` with public privacy, so paths are readable. The bundle identifier is `com.puremac.app` (`project.yml`). There is no log file. The last 1000 entries are also kept in memory (`Logger.entries`), but no screen displays them. Levels map as `.info` → info, `.warning` → default, `.error` → error, `.debug` → debug.

```
# live, while reproducing (info messages are not persisted by default, so stream them)
/usr/bin/log stream --level info --predicate 'subsystem == "com.puremac.app"'

# after the fact (default and error messages: warnings and errors)
/usr/bin/log show --last 30m --predicate 'subsystem == "com.puremac.app"'

# one category's messages
/usr/bin/log stream --level info --predicate 'subsystem == "com.puremac.app" AND eventMessage CONTAINS "Local AI Models"'
```

Use the full path `/usr/bin/log`: in zsh `log` can be shadowed. Run from Xcode, the same lines appear in the debug console. Row-level failures are also returned to the UI as the "Couldn't clean everything" alert text (`AppState.handleCleanOutcome`).

### Run the app against a fake home

```
CFFIXED_USER_HOME=<fixture-home> <DerivedData>/Build/Products/Debug/PureMac.app/Contents/MacOS/PureMac
```

`HOME` does not work. The app resolves the home folder through Foundation (`FileManager.homeDirectoryForCurrentUser`, `NSHomeDirectory()`), which reads `CFFIXED_USER_HOME` and otherwise the account's passwd entry, not the `HOME` variable. Checked on this macOS with a small binary: with `HOME=<fixture>` both calls still returned the real home; with `CFFIXED_USER_HOME=<fixture>` both returned the fixture. The fake home also holds that run's preferences (`Library/Preferences`), `~/.claude.json` for the worktree scanner and the hub cache for Hugging Face.

What stays real in a fake-home run, so never click Remove on anything you did not create:
- absolute paths: `/usr/local/bin/docker`, `/opt/homebrew/bin/docker`, `/Applications/*.app` (owner checks for AI Agent Data), `/opt/homebrew/bin/{git,ollama,hf}`;
- the process list, the Docker daemon (set `DOCKER_HOST=unix:///nonexistent.sock` so a real daemon cannot answer), and a local Ollama server (set `OLLAMA_HOST=127.0.0.1:1`, nothing listens there, or point it at a stub);
- environment variables of the shell that starts the app (`HF_HOME`, `HF_HUB_CACHE`, `XDG_CACHE_HOME`, `OLLAMA_HOST`, `DOCKER_HOST`).

## Adding a developer category

Checklist, in order. Each item names the file and the symbol to touch.

1. **Rules first.** Write the pure rules in `PureMac/Logic/Utilities/<Name>Support.swift` (what is listed, what is refused). Run `xcodegen generate` after adding any file.
2. **Enum.** `PureMac/Models/Models.swift` → `CleaningCategory`: add the case (the raw value is the display name and the Codable id), `icon`, `description`, `color`.
3. **Sets (a), (b), (c).** Decide each, write the decision in the row of `CategoryRulesTests.expected`:
   - (a) `CleaningCategory.smartScanExcluded` if Smart Scan, schedules and the headline total must not see it;
   - (b) `CleaningCategory.overviewExcluded` if the Overview must not count, select or clean it (everything in (a)'s exclusions belongs here too);
   - (c) `RemovalRisk.acknowledgedCategories` if removal is permanent user data or user work; then add the risks in `RemovalRisk.risks(for:items:)`, `action(for:repositories:)`, `note(for:)` and `readOnlyChecks(for:)` (the agent prompt).
4. **Row type.** `CleanableItem`: reuse `selectOnlyByHand`, `detail`, `requiresExplicitSelection`, `isSelectionBlocked`; add a path prefix to `isActionItem` for virtual rows. A new reason to skip bulk selection goes into `CleanableItem.isExcludedFromBulkSelection` (static) or `AppState.isExcludedFromBulkSelection` (live state), never into one bulk path.
5. **Scan.** `PureMac/Services/ScanEngine.swift` → the `scan(category:)` switch and a `scanXxx` function. User data rows: `isSelected: false`. If paths overlap another category, exclude them there (`scanUserCache` excludes `DevToolCaches.absolutePaths`). Honour `CleanupExclusions` (done in `AppState.applyingCleanupExclusions`). Inject anything that touches the machine (process list, tool lookup) like `DevToolCacheEnvironment`.
6. **Removal route.** `PureMac/Services/CleaningEngine.swift` → `cleanItems`: add an early `if item.category == .xxx { … continue }` before the generic path and after the exclusion check. First statement of the route: `isDockerDiskState(path)` and return `dockerDiskStateRefusal`. Then exact validation, re-validation right before acting, symlink/realpath check, tool CLI or API in preference to unlinking, Trash only where recoverable. Add a guard in `cleanWithAdminPrivileges` (developer categories never escalate) and make `isSafeToDelete(item:…)` return false for the category if the generic path must never act on it. Allow-list: add exact roots to `allowedDeletionRoots(home:)` only if the route calls `isSafeToDelete(resolvedPath:)`; never a broad folder. New injected parameters go at the end of `CleaningEngine.init` with production defaults.
7. **Survivors.** `AppState.handleCleanOutcome` / `survivingItems`: decide whether a refused row may raise the Full Disk Access prompt (AI Agent Data and tool-busy rows must not).
8. **UI.** `PureMac/Views/MainWindow.swift` → `advancedCategories`; `PureMac/Views/CategoryDetailView.swift` → `removalMethod(_:)` (Permanent or Move to Trash), row line (`secondaryLine`), notes via `CategoryResult.notes`.
9. **Strings.** Every new user-visible string in all 13 `PureMac/*.lproj/Localizable.strings` files under a `/* <Feature> */` comment: `ar de en es fr it ja pl pt-BR ru uk zh-Hans zh-Hant`; translate `uk` and `ru`, the rest use the English value. `LocalizationFilesTests` checks key parity, format specifiers and duplicate keys.
10. **Tests.** A new row in `CategoryRulesTests.expected` (the test fails without it); a row of the new kind in `CategoryRulesTests.makeRows` if it can be skipped by bulk selection; a route test in `DeletionDenyListTests`; a test file for the category with temp-folder fixtures and injected fakes (no real `docker`, `ollama`, `hf`, `uv`, Trash).
11. **Docs.** `docs/<TOPIC>.md` in the all-caps flat layout with the standard sections (What it finds, How it decides, How it removes, Safety invariants, Failure modes and logs, Testing, Related); a row in the [Map](#map), the log prefixes in [Debugging](#message-prefixes-per-category) and a fixture row above; one bullet in `README.md` → "What it does" → "System Cleaner" linking the doc; `docs/llms.txt` Product line and the "Removal behavior" paragraph (Trash, permanent or tool CLI/API). Do not edit the translated `docs/README.*.md`.
